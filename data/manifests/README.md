# Manifest policy

These files are generated by `src/build_manifests.py`. They describe source files and observations without copying or modifying the source datasets.

- `source_file_manifest.csv`: SHA-256 inventory of relevant repository and dataset files.
- `vision_operational_manifest.csv`: local camera captures grouped by observed session directory and restricted to replay use.
- `ae_row_manifest.csv`: AE engineered-feature records with partition eligibility and exclusion reasons.
- `ae_conflicting_feature_vectors.csv`: identical AE feature vectors associated with more than one label.
- `dataset_registry.json`: machine-readable source registry.
- `manifest_summary.json`: counts, observed groups and current freeze status.
- `hu_fdm_classification_manifest.csv`: frozen external classification split with temporal groups, archive provenance, processed-image hashes and explicit task limitations.
- `hu_fdm_classification_summary.json`: class/split counts and cross-split integrity checks for the compact working copy.

The absence of a print/job identifier is not repaired by inventing groups. Such records remain development-only. Conflicting labels are quarantined. A confirmatory train/validation/test split is created only after an eligible labeled source contains defensible independent groups.
